# 2단계 — 프로젝트 · 일감 코어

사람이 프로젝트를 만들고 일감을 추적한다. Redmine 의 핵심(프로젝트 · 멤버 · 일감 · 이력 · 트래커/상태/우선순위 · 기본 워크플로 · 필터 목록 · 첨부)을 M 부터 만든다. 서비스는 MCP 가 그대로 부를 수 있게 만든다(3단계).

**완료 기준:** 워크스페이스 A 에서 프로젝트를 만들고 멤버 · 프로젝트 역할을 주고, 일감을 만들고 · 고치고(워크플로) · 메모 · 첨부를 달고, 필터 목록으로 찾는다. 화면과 REST 가 같고, 프로젝트 경계 · 비공개 · 워크플로 · 잠금 테스트가 돈다.
