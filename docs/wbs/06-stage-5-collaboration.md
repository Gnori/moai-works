# 5단계 — 협업 (나중 후보에서 고르기)

첫 출시 범위(1 ~ 4단계) 다음에 팀이 일감을 함께 따라가는 데 필요한 것을 [나중 후보](../01-overview.md#32-나중-후보)에서 골라 만든다. 아래 넷은 **제안한 후보**다 — 무엇을 어떤 순서로 할지는 [D-05](08-decisions.md#d-05)에서 정하고, 고른 것은 **시작 전에 요구사항을 쓴다**(나중 후보라 지금은 요구사항이 없어 "요구사항" 칸이 비어 있다). 고르지 않은 후보는 이 단계에 줄을 더해 옮겨 온다.

**완료 기준:** 고른 후보마다 요구사항 · 설계를 쓰고, 화면 · REST(필요하면 MCP 도구)가 같은 판정으로 돈다. 받는 사람 · 검색 결과 · 내려받기에서도 프로젝트 경계(독자가 아니면 없는 것과 같다)가 지켜진다.
