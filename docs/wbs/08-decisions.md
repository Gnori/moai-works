# 정해야 할 것

작업을 막거나 방향을 바꾸는 결정이다. 설계 쪽마다 자세한 질문 목록이 있고(아래 [§2](#dc-detail)), 이 쪽에는 **사람이 정해야 하는 큰 것**만 모은다. 각 줄의 "제안"은 설계 쪽이 기본으로 적어 둔 답이다 — 이견이 없으면 그대로 진행한다.

정해지면 `상태` 에 날짜와 답을 적고, 설계를 바꾸는 결정이면 [ADR](../design/00-key-decisions.md)도 남긴다.

| <a id="d-04"></a>D-04 | 사람의 프로젝트 역할 정본을 Keycloak 조직 그룹에 둘까(moai-wiki 위키 역할과 같게) — 프로젝트 × 역할만큼 그룹이 생긴다 | 제안: 둔다, 그룹은 처음 역할을 줄 때 만든다. 규모 시험에서 한도를 잰다 | [2.1](03-stage-2-project-issue.md#w-2-1) |

| <a id="d-10"></a>D-10 | 운영 배치(클라우드/사내) · 규모 목표 | 미정 | 6단계 |

## 2. 설계 쪽의 자세한 질문

설계 쪽마다 "정해야 할 것" 표가 있고, 질문마다 그 쪽이 기본으로 고른 답이 적혀 있다. 그 기본대로 만들고, 바꾸려면 그 쪽과 이 쪽을 함께 고친다.

| 설계 쪽 | 질문 | 대표 질문 |
|---|---|---|
| [워크스페이스 · 권한](../design/03-workspace-identity.md) | 멤버의 `project.create` | 위 D-02 |
| [프로젝트 권한 §19](../design/04-project-permissions.md#pp-decisions) | P-1 ~ P-11 | 닫힌 프로젝트 쓰기는 409 · 모듈 꺼짐은 404 · 한 주체의 직접 역할은 하나 · 관리자에게 보관 · 삭제를 주지 않음 |
| [일감 §22](../design/05-issue-tracking.md#is-decisions) | I-1 ~ I-14 | 일감 삭제 방식 · 하위 일감 범위 · 첨부 상한 20MB · 읽기 전용 필드를 보내면 오류(Redmine 은 무시) · 메모만 쓰면 잠금 판을 올리지 않음 |
| [계획 · 시간 §15](../design/06-planning-time.md#pt-decisions) | PT-Q1 ~ PT-Q9 | 진척 가중에서 상위 일감 빼기 · 열린 일감이 남은 버전 닫기는 경고만 · 주 시작 월요일 |
| [MCP · AI Agent §31](../design/07-mcp-agents.md#mc-open) | 1 ~ 17 | 위 D-06 · D-07 · D-08 · 멱등 키 필수 · 엔드포인트별 서버 캐시 · 통합 검색 도구는 첫 출시에서 뺌 |
| [협업 §18](../design/08-collaboration.md#co-decisions) | CO-Q1 ~ CO-Q13 | Agent 에게 알림 없음 · 모르는 보낸 사람의 메일은 무시 · 검색 색인 하나 · 위키 휴지통 없음 |
| [연동](../design/09-integrations.md) | 그 쪽의 정해야 할 것 | Redmine 이관 범위 · Git 사람 대응 |
