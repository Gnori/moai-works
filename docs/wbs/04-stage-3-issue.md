# 3단계 — 일감

moai-wiki 의 페이지 자리에 일감을 만든다. 프로젝트 안에 일감이 여러 개 있고, 일감마다 **유형 · 상태 · 관리자 · 담당자 · 다섯 날짜(완료 기한 · 시작일 · 완료 예정일 · 완료일 · 종료일) · 상위 · 하위 일감 · 연결 일감 · 이력 · 댓글**이 있다. 서비스는 4단계의 MCP 도구가 그대로 부를 수 있게 만든다(행위자 · 경로를 문맥으로 받는다). moai-wiki 의 `page/` 코드와 `features/page` 화면을 본뜬다.

설계: [일감 설계](../design/05-issue.md) · [데이터 모델](../design/02-data-model.md). 결정: [ADR-019](../design/00-key-decisions.md#adr-019)(일감 번호 = 프로젝트 안 순번 — 2026-11-24 [ADR-030](../design/00-key-decisions.md#adr-030) 으로 대체: 일감은 워크스페이스 아래, 번호는 워크스페이스 안 순번, 프로젝트는 속성) · [ADR-020](../design/00-key-decisions.md#adr-020)(상태 고정 넷과 날짜 자동 채움) · [ADR-010](../design/00-key-decisions.md#adr-010)(본문 Markdown).

**완료 기준:** 워크스페이스 A 의 프로젝트에서 편집자가 요구사항 유형의 일감을 만들고, 관리자 · 담당자 · 날짜를 정하고, 하위 일감을 달고, 다른 일감과 "차단"으로 잇는다. 상태를 완료로 바꾸면 완료일이 오늘로 채워지고, 신규로 되돌리면 비워진다. 고칠 때마다 이력이 한 줄 남고 댓글이 그 사이에 보인다. 두 사람이 같은 일감을 고치면 나중 사람은 409 안내를 받는다. 큐레이터는 모든 프로젝트에서 일감을 만들고, 멤버는 읽고 댓글만 단다. 목록을 상태 · 유형 · 담당자로 거르고 정렬한다. 화면과 REST 가 같은 결과를 낸다.

## 이 단계에서 뺀 것

사용자 정의 워크플로 · 상태 · 필드, 프로젝트별 일감 유형, 관찰자, 비공개 일감 · 비공개 메모, 일괄 편집 · 복사, 저장한 질의, 칸반 보드, 내보내기는 [나중 후보](../01-overview.md#32-나중-후보)다. 다른 프로젝트로 옮기기와 다른 프로젝트와의 연결 일감은 2026-11-24 [3.9](04-stage-3-issue.md#w-3-9) 에서 했다(같은 워크스페이스 안).
