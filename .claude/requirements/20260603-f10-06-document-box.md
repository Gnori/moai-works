## 1. 요구사항 분석
### 1.1 문제 정의
사용자는 자신이 **상신/수신/진행/완료**한 결재 문서를 한 곳에서 조회·검색해야 하고,
완료된 문서는 **원본 그대로 불변 보존**되어 법적·감사 근거가 되어야 한다. 표준 문서함 뷰와
PDF 변환·보관을 제공한다.

### 1.2 목표
- **문서함 분류**: 상신함 · 수신(결재대기)함 · 진행함 · 완료함 · 임시저장함
- **원본 보존(불변)**: 완료 문서는 내용·결재선·서명 스냅샷 동결, 수정 불가
- **PDF 변환**(F8) · 완료 문서 보관 · 본문/제목/기안자 **검색**
- 테넌트 격리 · 권한(F0-07) · 조회 감사(F0-08)

## 2. 기능 정의
| ID | 기능 | 우선순위 |
|----|------|---------|
| F-001 | 문서함 분류 조회(상신/수신/진행/완료/임시저장) | Must |

| F-003 | PDF 변환·다운로드(F8) | Must |
| F-004 | 검색(제목·본문·기안자·기간·상태) | Must |

### 2.1 기능 상세
- **F-001 분류**: 현재 주체 기준 — 상신함(내가 기안) · 수신함(내 결재대기, F1-06 상위자/담당) · 진행함(결재중) · 완료함(승인/반려 종결) · 임시저장함(미상신 draft). 각 함은 페이징·정렬.
- **F-002 불변**: 종결 시 문서 본문·결재선·서명·첨부 메타를 `approval_archive` 스냅샷으로 동결(`immutable=true`). 이후 본문/결재선 수정 API 차단(409). 변경 필요 시 재기안만 허용.
- **F-003 PDF**: 완료 스냅샷을 F8 변환기로 PDF 렌더(결재선·서명 도장 포함). 생성물은 MinIO 보관, 다운로드 시 권한·격리 검사 + 감사 기록.
- **F-004 검색**: `tenant_id` 범위 내 제목·본문·기안자·상태·기간 필터. 본인 접근 가능 문서로 제한(기안자/결재자/열람권).
- **F-005 보관**: 완료 문서 장기 보관(삭제 불가, 정책상 보존기간). 재열람 시 원본 스냅샷 표출.

## 3. 기능 설계
### 3.1 기술 스택
Spring Boot · PostgreSQL(+RLS) · Flyway · MinIO(PDF) · F8 변환 서비스 · JUnit5

### 3.2 데이터 모델
- `approval_documents(id, tenant_id, drafter_id, title, status, box_state, created_at)` — box_state=draft/submitted/in_progress/completed
- `approval_archive(id, tenant_id, document_id, snapshot_json, pdf_object_key, immutable, archived_at)` — 종결 스냅샷
- 인덱스: `(tenant_id, drafter_id, status)` · `(tenant_id, box_state)` · 본문 검색 인덱스(GIN)

### 3.3 흐름 / API
```
완료 종결 → approval_archive 스냅샷(immutable) → F8 PDF 렌더 → MinIO 저장
문서함 조회 → box_state + 주체 역할 필터(F1-06) → 페이징
PDF 다운로드 → @RequiresPermission("approval:read") + 격리 + 감사(F0-08)
```
- `GET /api/approval/box/{state}` — 분류별 목록(@RequiresPermission `approval:read`)
- `GET /api/approval/documents/search?q=&status=&from=&to=` — 검색
- `GET /api/approval/documents/{id}` — 상세(스냅샷 우선)
- `GET /api/approval/documents/{id}/pdf` — PDF 다운로드
- 모든 엔드포인트 `tenant_id` 강제 · 교차 테넌트 차단(F0-01)
