## 1. 요구사항 분석
### 1.1 문제 정의
LDAP/AD 를 쓰는 기업은 **부서·사용자 조직 정보가 디렉터리에 이미 존재**한다. Keycloak User
Federation(F0-05)이 사용자/그룹을 가져오면, 그 결과를 **앱 조직(F1)에 매핑·동기화**해야 한다.
### 1.2 목표
- LDAP 그룹/OU → **부서(F1-01)** 매핑 · 사용자 → **배치(F1-03)** 매핑
- 동기화(주기/온디맨드) · 변경 반영 · 충돌/삭제 처리
- 매핑 규칙은 테넌트별 설정

## 2. 기능 정의

| F-001 | LDAP 그룹/OU → 부서 매핑 규칙 | Must |

## 3. 기능 설계
### 3.1 흐름
```
Keycloak(F0-05) ↔ LDAP → (이벤트/스케줄) → SyncService
  → 부서 upsert(F1-01) · 사용자 배치 upsert(F1-03) · diff 반영 · 감사(F0-08)
```
### 3.2 모델/설정
`org_sync_mappings(tenant_id, ldap_attr/group, target)` · `org_sync_runs(log)` · 멱등 upsert
