## 1. 요구사항 분석
### 1.1 문제 정의
다른 모듈(결재선·공유·알림·대시보드)과 사용자(조직도 화면)가 **조직 정보를 일관되게 조회**할
공용 API 가 필요하다. (부서원·상위자·트리·검색)
### 1.2 목표
- 조직도 트리 뷰 · 부서 상세(구성원) · 사용자 상세(소속·상위자)
- **사용자/부서 검색**(이름·직급·부서) · 상위자 체인(결재선 자동완성용)
- 성능(캐시) · 격리/권한

## 3. 기능 설계
### 3.1 API
`GET /org/tree` · `GET /departments/{id}` · `GET /users/{id}/org` · `GET /org/search?q=` · `GET /users/{id}/managers`(상위자 체인)
### 3.2 설계
- 읽기 모델/캐시(조직도) · 검색은 PG(이름·부서) + 후속 전체검색 연계 가능 · 권한·격리
