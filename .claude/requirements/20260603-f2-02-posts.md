## 1. 요구사항 분석
### 1.1 문제 정의
게시판에 글을 **작성·수정·삭제·조회**하고, 목록·검색·**공지 고정**을 제공한다. 새 글은
알림(F3)·지식화(F7) 대상이 된다.
### 1.2 목표
- 게시글 CRUD(제목·본문·상태) · 작성자/권한 · soft delete
- 목록(페이지·정렬·검색) · **공지 상단 고정** · 조회수
- 새 글 → 알림(F3) · 본문 → 지식화(F7) 훅

## 3. 기능 설계
### 3.1 데이터 모델
`posts(id, tenant_id, board_id, author_id, title, body, pinned, view_count, status, created_at, updated_at)` + 인덱스 `(tenant_id, board_id, created_at)`
### 3.2 API
`/boards/{id}/posts` CRUD · `GET /boards/{id}/posts?page&sort&q` · 권한(게시판 범위 + `board:write`)
