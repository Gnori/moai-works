## 1. 요구사항 분석
### 1.1 문제 정의
사용자가 하루를 시작할 때 **AI가 오늘 할 일·중요 항목·일정을 요약 브리핑**해준다. (메신저 AI
요약·할일추출과 동일한 moai-agent 기반)
### 1.2 목표
- 사용자 컨텍스트(오늘 일정·미처리 업무·중요 알림) 수집 → **F13 Agent** 요약
- 대시보드 상단 **브리핑 카드** · (옵션) 예약 생성(F14, 아침 브리핑)
- 출처/링크 포함 · 권한·격리

## 2. 기능 정의
| ID | 기능 | 우선순위 |
|----|------|---------|
| F-001 | 브리핑 컨텍스트 수집(집약) | Must |

## 3. 기능 설계
### 3.1 흐름
```
컨텍스트(일정·미처리·알림) 집약(H-01) → F13 Agent 요약 → 브리핑 카드
(옵션) F14 스케줄 → 아침 브리핑 생성/푸시(F3)
```
### 3.2 의존
F13(AI Agent) 미완 시 placeholder/규칙 기반 요약 → F13 완성 후 전환
