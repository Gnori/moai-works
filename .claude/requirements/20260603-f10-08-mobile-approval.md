## 1. 요구사항 분석
### 1.1 문제 정의
결재자는 외근·이동 중에도 **결재 대기**를 빠르게 처리해야 한다. 모바일 환경에 맞춰
**대기 조회 → 승인/반려**를 경량 API로 제공하고, **푸시 알림**(F3)으로 즉시 인지시키며,
보안을 위해 승인 시 **간편 인증**(Keycloak 재인증)을 요구한다. 데스크톱 결재 로직(F10 코어)을
재사용하며 화면/응답만 모바일 최적화한다.

### 1.2 목표
- 모바일 최적 **대기함/상세 조회** API (경량 페이로드·페이징)
- **승인/반려**(F10 코어 액션 재사용) + 의견 입력 · 격리(F0-01)
- **푸시 알림**(F3 push 채널) — 신규 상신·반려·완료 시
- **간편 인증**: 승인 직전 Keycloak 재인증(생체/PIN step-up)으로 본인 확인

## 2. 기능 정의
| ID | 기능 | 우선순위 |
|----|------|---------|
| F-001 | 모바일 대기함 조회(경량·페이징·정렬) | Must |
| F-002 | 모바일 결재 상세 조회(라인·본문 요약) | Must |
| F-003 | 모바일 승인/반려(의견) — F10 코어 재사용 | Must |
| F-004 | 푸시 알림 연동(F3) — 상신/반려/완료 | Must |
| F-005 | 간편 인증(Keycloak step-up) 후 승인 확정 | Should |

### 2.1 기능 상세
- **F-001/002**: 데스크톱과 동일 데이터원, 응답을 모바일용 경량 DTO로 가공(불필요 첨부/이력 생략, 요약 필드). 대상은 `@RequiresPermission("approval:read")` + 본인 대기건만.
- **F-003**: 승인/반려는 **F10 코어 서비스** 호출(중복 비즈로직 금지). `@RequiresPermission("approval:approve")`. 상위자·라인 정보는 [F1-06](./20260603-f1-06-org-query-view.md) 참조.
- **F-004**: F10 상태 전이 이벤트 → [F3](./20260603-f3-notification-master.md) push 채널 발송(디바이스 토큰 기반). 알림 클릭 → 상세 딥링크.
- **F-005**: 승인 요청에 step-up 토큰 동반 → Keycloak([F0-03](./20260603-f0-03-authentication.md)) 재인증 검증 통과 시 확정. 실패 시 401. 처리 결과는 감사([F0-08](./20260603-f0-08-audit-log.md)) 기록.

## 3. 기능 설계
### 3.1 데이터 모델
- 신규 결재 테이블 없음 — **F10 코어 재사용**(`approval_doc`, `approval_line` 등, 모두 `tenant_id` 격리).
- `device_token(id, tenant_id, user_id, platform, token, updated_at)` — 푸시 발송 대상(F3 공유 가능 시 재사용).
- 모바일 응답 DTO는 코어 엔티티 투영(저장 없음).

### 3.2 API (모바일 최적)
```
GET  /api/m/approvals/pending?cursor=&size=     # 대기함(경량·커서 페이징)
GET  /api/m/approvals/{id}                      # 상세(요약)
POST /api/m/approvals/{id}/approve              # {opinion, stepUpToken} → 승인
POST /api/m/approvals/{id}/reject               # {opinion, stepUpToken} → 반려
POST /api/m/devices                             # {platform, token} 디바이스 등록
```
- 모든 응답 `tenant_id` 격리 · 경량 페이로드 · 커서 페이징.

### 3.3 흐름
```
상신/반려/완료(F10 상태전이) → F3 push → 모바일 알림
탭 → GET pending/상세 → approve(stepUpToken)
  → Keycloak 재인증 검증 → F10 코어 승인 → F0-08 감사 → F3 결과 알림
```
