## 1. 요구사항 분석
### 1.1 문제 정의
질의에 대해 **관련 지식을 정확히 검색**해야 RAG 답변 품질이 난다. 의미검색(벡터)+키워드를
결합하고 리랭크하며, **반드시 권한 필터(F7-04)**를 건다.
### 1.2 목표
- **하이브리드 검색**(Qdrant 의미 + 키워드) + **리랭크** · top-k
- 권한 필터(F7-04) 강제 결합 · 다중 소스(문서/대화/메일) 통합
- 쿼리 확장·메타 필터(부서·기간·소스) · 성능
