## 1. 요구사항 분석
### 1.1 문제 정의
로그인 후 첫 화면 = **개인 업무 대시보드**. 오늘 일정·주요 알림·최근 문서·미처리 업무를 한눈에
보고, **AI 업무 브리핑**으로 하루를 정리받는다.
### 1.2 목표
- **위젯 대시보드**(일정·알림·최근문서·미처리업무) · 개인화(배치·on/off)
- **AI 업무 브리핑**(F13 Agent — 오늘 할 일·중요 항목 요약)
- 각 위젯은 소스 모듈 API 집약(신규 비즈로직 최소)
### 1.3 제약
- 위젯은 **소스 모듈 완성 시 점등**(일정/업무/문서는 Wave 2) — 단계적 활성화
- 격리(F0-01)·권한·성능(집약 캐시)
