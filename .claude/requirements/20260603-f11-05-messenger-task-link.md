- **상위**: [F11 마스터](./20260603-f11-task-master.md) · **의존**: [F11-01 Task](./20260603-f11-01-task-core.md) · **F5 메신저**(AI 할일 추출)

## 1. 요구사항 분석
### 1.1 문제 정의
메신저 대화에서 AI가 **할 일·담당자·기한을 추출**(F5)하면, 이를 **업무(Task)로 자동/수동 생성**해
업무관리로 흘려보낸다.
### 1.2 목표
- F5 추출 결과(할일·담당·기한) → Task 생성(F11-01)
- 메시지 ↔ 업무 링크(역추적) · 사용자 확인(자동/수동) · 격리
