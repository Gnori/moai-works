# F15 — 외부 시스템 연계 마스터 (ERP · 인사 · 회계 · MCP · 레거시)

## 메타데이터
- **작성일**: 2026-06-03 · **작성자**: GnoRi · AI Assistant
- **상태**: 1단계 — 요구사항 분석 (L1 도메인 마스터) · **규모**: complex(마스터)
- **우선순위**: medium-high (Wave 6 — 확장) · **연관**: 의존 [F0](./20260603-f0-saas-foundation-master.md)·[F13 AI Agent](./20260603-f13-ai-agent-master.md) · 연계 F12 인사·F10 회계결재·F4 문서

## 1. 요구사항 분석
### 1.1 문제 정의
그룹웨어는 고립되면 안 된다. 기업의 **ERP·인사·회계·문서관리(DMS)·업무포털·레거시** 와
연동하고, **MCP**로 AI Agent 가 외부 도구/데이터에 접근하게 한다.
### 1.2 목표
- **커넥터 프레임워크**(공통 추상: 인증·매핑·동기화·에러) + 시스템별 어댑터
- ERP·인사(F12)·회계(F10)·DMS(F4)·업무포털(SSO) 연동
- **MCP 연동**: F13 Agent 가 외부 MCP 서버의 도구/리소스 사용
- 레거시 어댑터(구형 시스템)
### 1.3 제약
- F0 격리/권한 · 시크릿 보관 · 테넌트별 연동 설정 · 동기화 멱등·재시도

## 3. 기능 설계 (토대)
### 3.1 아키텍처
```
[moai-works] ──커넥터 프레임워크(F15-01)──▶ [외부 시스템]
   ├─ ERP/인사/회계/DMS 어댑터 (동기화·매핑)
   ├─ SSO/포털 (Keycloak 브로커링)
   └─ MCP 클라이언트(F15-07) ──▶ MCP 서버(외부 도구) ◀── F13 Agent 도구로 노출
```
