## 1. 요구사항 분석
### 1.1 문제 정의
신규 입사자는 질문이 많다. **온보딩 Agent**가 회사·부서·직무 지식(F7)을 기반으로 답하고,
필요한 문서를 추천하며, 교육 이력·다음 할 일을 안내한다.
### 1.2 목표
- **신규자 Q&A**(F7 지식 기반·출처) · **필요 문서 추천**(F4/F7)
- **교육 이력 확인**(F9-04 진도) · **다음 할 일·업무 수행 방법 안내**
- F13 온보딩 Agent로 구현 · 권한 컨텍스트(F13-06)·정직성(F13-10)

### 3.1 흐름
```
신규자 질문 → 온보딩 Agent(F13-05) → knowledge_search(F7-08, 권한범위) + 진도(F9-04)
 → 출처 기반 답변·문서 추천·다음 단계 안내
```
### 3.2 의존
