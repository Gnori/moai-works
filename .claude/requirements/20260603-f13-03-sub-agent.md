## 1. 요구사항 분석
### 1.1 문제 정의
복합 작업(예: "지난주 회의록 모아 분기 보고서 초안")은 **하위 단계로 분할**해 순차/병렬 실행 후
합성해야 한다. Sub Agent 가 이를 담당.
### 1.2 목표
- 작업 분할(plan) · 하위 단계 실행(도구/도메인 Agent) · 결과 합성
- 단계 실패 처리·재시도 · 컨텍스트 전파 유지 · 무한 루프 방지(recursion limit)

## 2. 기능 정의

|----|------|---------|
| F-001 | 작업 분할(plan) | Must |

## 3. 기능 설계
### 3.1 흐름
```
복합 작업 → plan(분할) → 단계 실행(도구/Agent) → 합성 → 반환
(recursion_limit·단계 한도로 폭주 방지)
```
