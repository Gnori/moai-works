## 1. 요구사항 분석
### 1.1 문제 정의
**MCP(Model Context Protocol)** 로 외부 시스템의 도구/리소스를 표준 방식으로 연결하면, F13
AI Agent 가 사내·외부 도구를 확장 사용할 수 있다. (moai-agent 의 MCP 지원 활용)
### 1.2 목표
- **MCP 클라이언트**: 외부 MCP 서버 연결(테넌트별 등록) · 도구/리소스 발견
- 발견된 MCP 도구를 **F13-04 Tool 레지스트리에 동적 등록** → Agent tool-call
- **권한·격리 가드(F13-06)**: MCP 도구 호출도 테넌트/권한 강제 · 위험 도구 승인(F13-10)

### 1.3 제약
- MCP 서버 신뢰·인증 · 도구 화이트리스트 · 테넌트별 격리 · 감사(F0-08)

## 3. 기능 설계
### 3.1 흐름
```
MCP 서버 등록 → 클라이언트 연결 → 도구/리소스 발견
 → F13-04 Tool 래핑(컨텍스트 가드) 등록 → Agent tool-call
 → 호출 시 권한/격리 가드 + 위험 도구 승인 + 감사
```
### 3.2 참고
moai-agent MCP 지원(ToolSearch/MCP 도구 패턴) 활용
