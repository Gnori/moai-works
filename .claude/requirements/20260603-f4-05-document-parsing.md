## 1. 요구사항 분석
### 1.1 문제 정의
업로드 문서를 **파싱해 텍스트·구조를 추출**해야 미리보기·검색·요약·지식화가 가능하다.
Java 백엔드라 **Apache POI**(+pdf 라이브러리)로 서버사이드 파싱한다.
### 1.2 목표
- **docx(XWPF)·xlsx(XSSF)·pptx(XSLF)** + **PDF** 텍스트·구조 추출
- 미리보기(HTML/이미지 렌더) · 추출 결과 캐시
- F7 지식화·검색(F4-07)의 입력 제공

### 1.3 제약
- F8 문서스택과 **POI 공통 사용**(중복 회피) · 대용량 비동기 처리

## 3. 기능 설계
### 3.1 스택
Apache POI(XWPF/XSSF/XSLF) · PDFBox · 비동기 워커(moai-works-api 또는 ai 서비스)
### 3.2 흐름
```
업로드(F4-01) → (async) 파싱 워커(POI/PDFBox) → 텍스트/구조/미리보기
 → 캐시 + F7 지식화 인덱싱 + F4-07 검색 색인
```
