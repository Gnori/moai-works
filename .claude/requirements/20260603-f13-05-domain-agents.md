## 1. 요구사항 분석
### 1.1 문제 정의
영역별 전문 **도메인 Agent**(지식·문서작성·메신저·이메일·일정·전자결재·온보딩·예약·레거시)를
정의한다. 각 Agent = 시스템 프롬프트 + 도메인 도구셋(F13-04) + 컨텍스트.
### 1.2 목표
- 도메인 Agent 정의(역할·프롬프트·도구셋) · Main Agent(F13-02) 가 위임
- 각 Agent 가 해당 모듈 도구로 작업 수행(F5/F6/F8 등의 AI 기능 백엔드)
