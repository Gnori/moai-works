## 1. 요구사항 분석
### 1.1 문제 정의
문서는 수정될 때마다 **버전**이 쌓이고, 이전 버전 **복원·이력 조회**가 필요하다. (F8 문서편집의
snapshot/exported 버전과도 정합)
### 1.2 목표
- 새 업로드/저장 시 **버전 증가**(원본 보존) · 버전 목록·다운로드·복원
- 버전별 메타(작성자·시각·코멘트) · quota(버전 누적) 고려

## 2. 기능 정의

|----|------|---------|
| F-001 | 버전 생성(업로드/저장 시) | Must |

## 3. 기능 설계
### 3.1 데이터 모델
`file_versions(id, file_id, version, storage_key, size, author_id, comment, created_at)` · 현재 버전 포인터
### 3.2 설계
복원 = 해당 버전을 새 최신으로 · F8 exported/snapshot 연동 · quota
