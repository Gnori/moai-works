## 1. 요구사항 분석
### 1.1 문제 정의
사용자/시스템 요청의 **의도를 파악**해 적절한 도메인 Agent/도구로 **라우팅·오케스트레이션**하는
Main Agent. (메신저 @Agent·대시보드 브리핑·문서작성 등 모든 진입이 여기로)
### 1.2 목표
- 의도 분류(요청 → 도메인) · 도메인 Agent 위임 · 다단계 조율(필요 시 F13-03 Sub)
- 도구 직접 호출 또는 도메인 Agent 호출 · 응답 합성 · 컨텍스트 유지

## 2. 기능 정의
| ID | 기능 | 우선순위 |
|----|------|---------|
| F-001 | 의도 분류·라우팅 | Must |

| F-004 | 응답 합성·출처 | Must |

## 3. 기능 설계
### 3.1 흐름
```
요청 → Main Agent(의도 분류) → {도메인 Agent | 도구 직접} 위임
 → (복합 시 F13-03 Sub 분할) → 결과 합성 → 응답(출처 포함)
```
### 3.2 설계
LangGraph 라우팅 · 도메인 Agent 레지스트리(F13-05) · 컨텍스트(F13-06) 유지
