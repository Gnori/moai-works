## 1. 요구사항 분석
### 1.1 문제 정의
OOXML 라운드트립(열기→편집→내보내기)의 **충실도/손상을 자동 검증**하지 않으면 프로덕션에서
파일 손상이 터진다. 실제 기업 파일 코퍼스로 **회귀 테스트**한다. (F8 성패를 가르는 안전망)
### 1.2 목표
- 실제 docx/xlsx/pptx **코퍼스**(수십~수백) · 열기→편집(또는 무편집)→내보내기 → **diff**
- 손상(파싱 실패·OPC 무결성)·손실(요소 사라짐) 자동 검출 · CI 회귀
- 충실도 메트릭·리포트
