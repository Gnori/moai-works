## 1. 요구사항 분석
### 1.1 문제 정의
문서는 **누가 보고/편집/공유**할 수 있는지 통제가 필요하다. 공간·폴더·파일 단위 권한과
**공유 링크**를 제공한다.
### 1.2 목표
- 권한 레벨(view/edit/manage) · 대상(사용자·부서·역할) · **상속**(공간→폴더→파일)
- **공유 링크**(만료·비번·범위) · 격리

## 2. 기능 정의
| ID | 기능 | 우선순위 |
|----|------|---------|
| F-001 | 권한 부여(view/edit/manage × 사용자/부서/역할) | Must |

## 3. 기능 설계
### 3.1 데이터 모델
`file_acl(target_type=space/folder/file, target_id, grantee_type=user/dept/role, grantee_id, level)` · `share_links(id, file_id, token, expires, password)`
### 3.2 평가
상속 + 재정의 → 유효권한 · 다운로드/편집 시 검사 · 격리
