## 1. 요구사항 분석
### 1.1 문제 정의
게시글에 **파일을 첨부**한다. 저장은 **F4 파일드라이브(MinIO)** 토대를 재사용한다(중복 구현
회피). 첨부 권한은 게시글 가시성에 종속.
### 1.2 목표
- 첨부 업로드/다운로드(F4 오브젝트 스토리지) · 게시글 연결
- 첨부 권한 = 게시글 권한 상속 · 미리보기(이미지) · 용량/타입 제한(F0-09 quota)

## 2. 기능 정의
| ID | 기능 | 우선순위 |
|----|------|---------|
| F-001 | 첨부 업로드(F4) + 게시글 연결 | Must |
| F-002 | 다운로드(권한 = 게시글) | Must |
| F-003 | 타입/용량 제한·바이러스/검증 | Should |
| F-004 | 이미지 미리보기·썸네일 | Should |

## 3. 기능 설계
### 3.1 설계
- 저장은 **F4 API 재사용**(MinIO 버킷·테넌트 네임스페이싱). `post_attachments(post_id, file_id)` 연결
- 다운로드 = presigned URL(권한 확인 후) · quota 차감(F0-09)
### 3.2 의존
F4 미완 시 임시 자체 첨부 → F4 완성 후 이관(마이그레이션 메모)
