## 1. 요구사항 분석
### 1.1 문제 정의
`.pptx` 는 POI **XSLF 가 가장 약하고** Univer Slides OSS 도 미성숙 → **고충실 편집 난이도 최상**.
**Raw XML Patch** 의존도가 크다. (마스터 결정: pptx 는 범위 조정 가능 — 보기·생성 위주)
### 1.2 목표
- pptx 인바운드(XSLF → Univer Slide, 가능 범위) + 아웃바운드 + **Shadow + Raw XML Patch**
- **현실적 기대치**: 편집 충실도 제한 시 "보존+읽기전용" 또는 보기/생성 위주 · fidelity(F8-11)

### 1.3 제약
- XSLF 한계 · Raw XML Patch 안전성 · 범위는 마스터 결정 따름(편집 vs 보기/생성)
