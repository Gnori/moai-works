## 1. 요구사항 분석
### 1.1 문제 정의
대시보드의 **핵심 위젯**들 — 오늘 일정·주요 알림·최근 문서·미처리 업무 — 을 각 소스 모듈에서
집약해 보여준다.
### 1.2 목표
- 위젯 4종: **오늘 일정 / 주요 알림(F3) / 최근 문서(F4) / 미처리 업무**
- 각 위젯 = 소스 모듈 API 집약 · "더보기" 링크 · 권한/격리
- 소스 미완성(Wave2) 시 placeholder → 완성 시 점등
