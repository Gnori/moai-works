## 1. 요구사항 분석
### 1.1 문제 정의
받은 메일에 대한 답장 작성에 시간이 소요된다. **메일 스레드 컨텍스트 + 톤 + 사내 지식(F7)**을
기반으로 **답변 초안**을 자동 생성하고, 사용자가 검토·수정 후 F6-02 송신으로 발송한다.
AI는 초안만 생성하며 **자동 송신은 금지**(사용자 명시 승인 필수).
### 1.2 목표
- 스레드 컨텍스트(원문·이전 답장·요약 F6-03) 기반 초안 생성
- **톤 선택**(정중/간결/친근/공식) · 언어 자동 감지 · 길이 옵션
- **지식 근거**(F7 RAG)로 사실 기반 답변 · 근거 출처 표시
- F13 미완 시 **placeholder/fallback**(템플릿 기반 또는 비활성) · 격리(F0-01)

## 3. 기능 설계
### 3.1 데이터 모델
`mail_draft(id, tenant_id, message_id, thread_id, user_id, body, tone, language, sources[jsonb], status=generated/edited/sent/discarded, created_at)`
- 모든 행 `tenant_id` (F0-01 RLS) · `sources`: F7 지식 청크 id·출처 메타
### 3.2 생성 흐름
1. 사용자가 메일 스레드에서 "AI 답변 초안" 요청
2. 컨텍스트 조립: 원문 + 스레드 이력 + 요약(F6-03) + 옵션(톤/언어/길이)
3. **F7 RAG 검색** → 관련 지식 청크 → 프롬프트 컨텍스트 주입
4. **F13 Agent 호출** → 초안 body + 사용된 출처 반환 → `mail_draft` 저장(status=generated)
5. 프런트 에디터 표시 → 사용자 수정(status=edited) → **F6-02 송신**(status=sent)
6. 권한(F0-07): 본인 메일박스 한정 · 감사(F0-08): 생성·송신 기록
### 3.3 Fallback (F13/F7 미완)
- **F13 미완**: 템플릿 기반 초안(인사+요약 회신 골격) 또는 기능 비활성 + "AI 미연동" 안내
- **F7 미완**: 지식 근거 생략 · `sources=[]` · 컨텍스트는 스레드만 사용
### 3.4 API (`/api/v1/mail`)
| Method | Path | 설명 |
|--------|------|------|
| POST | `/messages/{id}/draft` | 답변 초안 생성(tone/language/length) |
| GET | `/drafts/{id}` | 초안 조회 |
| PATCH | `/drafts/{id}` | 초안 수정(body) |
| POST | `/drafts/{id}/send` | 검토 후 송신(F6-02 연계) |
| DELETE | `/drafts/{id}` | 초안 폐기 |
