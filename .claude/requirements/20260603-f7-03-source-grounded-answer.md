## 1. 요구사항 분석
### 1.1 문제 정의
RAG 답변은 **출처(인용)를 명시**해야 신뢰·검증 가능하다. 검색 청크 기반으로 답하고, **근거가
없으면 모른다고** 한다(환각 방지).
### 1.2 목표
- 검색 청크(F7-02) → LLM 답변 + **인용/출처 링크**(원문 문서/메시지)
- 근거 부족 시 "모름"·추가질의 · 출처 신뢰도 표시
