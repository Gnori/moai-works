## 1. 요구사항 분석
### 1.1 문제 정의
문서는 **공간(부서/프로젝트/개인)** 안의 **폴더 트리**로 정리된다. 공간·폴더 CRUD·이동 토대.
### 1.2 목표
- 공간 유형: **부서**(F1 부서 연동)·**프로젝트**·**개인**
- 폴더 트리 CRUD·이동·정렬 · 파일 배치 · 격리

## 2. 기능 정의
| ID | 기능 | 우선순위 |

`spaces(id, tenant_id, type, owner_ref, name)` · `folders(id, tenant_id, space_id, parent_id, name, path)` · `files.folder_id`
