- **상위**: [F4 마스터](./20260603-f4-filedrive-master.md) · **의존**: [F4-05 파싱](./20260603-f4-05-document-parsing.md) · 연계 **F7 지식관리**

## 1. 요구사항 분석
### 1.1 문제 정의
문서를 **메타/내용으로 검색**하고, 저장 문서를 **자동 지식화(F7 RAG)** 해 질의응답·작성에 활용한다.
### 1.2 목표
- 메타 검색(이름·작성자·태그) + **내용 검색**(파싱 텍스트)
- 저장/갱신 시 **자동 인덱싱 → F7**(임베딩·Qdrant) · 권한 반영 검색
- 최신성/권한 필터(본인이 접근 가능한 문서만)

## 3. 기능 설계
### 3.1 흐름
```
파싱 텍스트(F4-05) → 색인(메타: PG, 내용: F7 Qdrant)

```
